# Contributing to this repo

Thank you for contributing!

## Step 1 — Clone

Clone the repository:

git clone <REPOSITORY_URL>

Move into the project:

cd <this_folder>

## Step 2 — Create a Branch

Never work directly on main.

Create your branch:

git checkout -b student/<your-number>

Example:

git checkout -b student/07

## Step 3 — Make Your Changes

Open your assigned file:

students/student-07.md

Update your information.

## Step 4 — Check Your Changes

Run:

git status

Check that you have modified only your assigned file.

## Step 5 — Commit

git add students/student-07.md

git commit -m "feat: update student profile"

## Step 6 — Push

git push -u origin student/07

## Step 7 — Create Pull Request

Go to GitHub.

Create a Pull Request:

student/07 → main

Use the title:

[Student 07] Update student profile

## Step 8 — Review

Wait for the instructor to review your Pull Request.

Do not merge your own PR unless instructed.

## Important Rules

❌ Do not push directly to main.

❌ Do not modify another student's file.

❌ Do not modify README.md.

❌ Do not modify CONTRIBUTING.md.

✅ Work only on your assigned file. asjd

✅ Use a separate branch.

✅ Create a Pull Request.

✅ Write a meaningful commit message.
